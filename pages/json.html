    Importer le module

    Le module json permet de traiter les données contenues dans les fichiers .json. Les données sont présentées sous forme de dictionnaires et de listes imbriqués. On peut ouvrir ces fichiers avec un éditeur de texte. 

    import json

    Lire un fichier JSON

    Fichier JSON Python 
    {
    "nom": "Paul",
    "age": 14
}
    		 
    with open("my_file.json", "r", encoding="utf-8") as f:
    data = json.load(f)
    • "r" : indique le mode lecture
    • encoding="utf-8" : précise le type d'encodage

    Résultat :

    {'nom': 'Paul', 'age': 14}

    Lire une chaîne JSON

    Texte JSON Python 
    my_json_text = '{"nom": "Paul", "age": 14}'
    		 
    data = json.loads(my_json_text)

    Résultat :

    {'nom': 'Paul', 'age': 14}

    Accéder aux données

    L'accès aux données se fait de façon classique en utilisant les listes et les dictionnaires. Il peut donc être utile de vérifier le type de données obtenues quand on découvre un fichier ou un contenu json. 

    print(type(data))

    Résultats possibles : dict ou list.

    Écrire dans un fichier

    Données Python 
    data = {
    "nom": "Paul",
    "age": 14
}
    		 
    with open("my_file.json", "w", encoding="utf-8") as f:
    json.dump(data, f)
    • "w" : indique le mode écriture
    • encoding="utf-8" : précise le type d'encodage

    Convertir en chaîne JSON

    Données Python 
    data = {
    "nom": "Paul",
    "age": 14
}
    		 
    text = json.dumps(data)

    Résultat :

    '{"nom": "Paul", "age": 14}'

    Afficher proprement des données JSON

    Python Résultat en JSON 
    json.dump(data, f, indent=4)

    ou

    text = json.dumps(data, indent=4)
    		 
    {
    "nom": "Paul",
    "age": 14
}

    Conserver les accents dans des données JSON

    Python Résultat sans Résultat avec 
    json.dump(
    data,
    f,
    ensure_ascii=False
)
    		 
    {
    "pr\u00e9nom": "L\u00e9o"
}
    		 
    {
    "prénom": "Léo"
}

    Trier les clés dans des données JSON

    Python Résultat sans Résultat avec 
    json.dump(
    data,
    f,
    sort_keys=True
)
    		 
    {
    "age": 14,
    "nom": "Paul",
    "classe": "4A"
}
    		 
    {
    "age": 14,
    "classe": "4A",
    "nom": "Paul"
}

    Modifier un fichier JSON

    Pour modifier un fichier ou un contenu json, il est d'abord nécessaire de le lire (json.load() ou json.loads()), puis modifier les données, pour pouvoir ensuite écrire (json.dump() ou json.dumps()).

    Correspondance automatique JSON ↔ Python

    JSON Python
    objet {} dict
    tableau [] list
    chaîne str
    entier int
    décimal float
    true True
    false False
    null None
