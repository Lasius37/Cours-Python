    Importer le module

    Le module csv permet de traiter les données contenues dans les fichiers .csv. Les données sont présentées sous forme de tableaux. Ces fichiers sont généralement édités avec un tableur, mais on peut aussi les ouvrir avec un éditeur de texte. 

    import csv

    Lire un fichier CSV

    Permet de lire chaque ligne sous forme d'une liste.

    Fichier CSV Python 
    Dupont;Paul;14
Durand;Marie;12
    		 
    with open("my_file.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f, delimiter=";")

    for line in reader:
        print(line)
    • "r" : indique le mode lecture
    • encoding="utf-8" : précise le type d'encodage
    • On peut convertir reader en une liste : data = list(reader)

    Résultat :

    ['Dupont', 'Paul', '14']
['Durand', 'Marie', '12']

    Lire un fichier CSV avec des titres

    Permet de lire chaque ligne sous forme d'un dictionnaire.

    Fichier CSV Python 
    Nom;Prénom;Age
Dupont;Paul;14
Durand;Marie;12
    		 
    with open("my_file.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f, delimiter=";")

    for line in reader:
        print(line)
    • "r" : indique le mode lecture
    • encoding="utf-8" : précise le type d'encodage

    Résultat :

    {'Nom': 'Dupont', 'Prénom': 'Paul', "Age": '14'}
{'Nom': 'Durand', 'Prénom': 'Marie', "Age": '12'}

    Paramètres importants

    Paramètre Utilité Remarque 
    delimiter=";"
    		 choisir le séparateur de données CSV français courant 
    encoding="utf-8"
    		 gérer les accents recommandé pour les projets francophones 
    newline=""
    		 éviter d'incorporer une ligne vide surtout utile sous Windows

    Créer ou écraser un fichier CSV

    with open("my_file.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f, delimiter=";")
    • "w" : indique le mode écriture
    • encoding="utf-8" : précise le type d'encodage

    Ajouter des lignes dans un fichier CSV

    with open("my_file.csv", "a", newline="", encoding="utf-8") as f:
    writer = csv.writer(f, delimiter=";")
    • "a" : indique le mode ajout
    • encoding="utf-8" : précise le type d'encodage

    Écrire une ligne à partir d'une liste

    Python Résultat en CSV

    Le code suivant est à taper à l'intérieur du with.

    writer.writerow(["Nom", "Prénom", "Age"])
writer.writerow(["Dupont", "Paul", 14])
writer.writerow(["Durand", "Marie", 12])
    		 
    Nom;Prénom;Age
Dupont;Paul;14
Durand;Marie;12

    Écrire plusieurs lignes à partir d'une liste de lignes

    Python Résultat en CSV 
    data = [
    ["Nom", "Prénom", "Age"],
    ["Dupont", "Paul", 14],
    ["Durand", "Marie", 12]
]

    Le code suivant est à taper à l'intérieur du with.

    writer.writerows(data)
    		 
    Nom;Prénom;Age
Dupont;Paul;14
Durand;Marie;12

    Écrire à partir de dictionnaires

    titles = ["Nom", "Prénom", "Age"]
data = {"Nom": "Dupont", "Prénom": "Paul", "Age": 14}

with open("my_file.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=titles, delimiter=";")  # fieldnames détermine les titres de colonnes

    writer.writeheader()  # écrit la ligne d’en-tête
    writer.writerow(data)  # écrit la ligne suivante
