Importer le module

Le module datetime permet de prendre en compte les dates et heures. Des calculs de durées sont possibles. 

from datetime import datetime, date, timedelta  # importer le nécessaire seulement

Obtenir la date actuelle

datetime.now()  # renvoie la date et l'heure actuelle
date.today()  # renvoie la date actuelle

Créer une date

date(2026, 6, 19)  # renvoie un objet date, le 19/06/2026
datetime(2026, 6, 19, 14, 30)  # renvoie un objet datetime, le 19/06/2026 à 14:30:00

Convertir texte ↔ date

datetime.strptime(  # convertit une chaîne en objet datetime
    "19/06/2026",  # la date à convertir
    "%d/%m/%Y"  # dont on précise le format
)

my_date.strftime("%d/%m/%Y")  # convertit un objet date ou datetime en chaîne
jour %A ↔ "vendredi"
%a ↔ "Ven"
%d ↔ "19"
mois %m ↔ "06"
%B ↔ "juin"
%b ↔ "jui"
année %Y ↔ "2026"
%y ↔ "26"
heure %H ↔ "14"
minute %M ↔ "30"
seconde %S ↔ "05"

Ajouter une durée

next_week = datetime.now() + timedelta(days=7)

Soustraire deux dates

delta = date2 - date1

Récupérer un intervalle de temps

delta.days  # ou .seconds, .total_seconds ou .microseconds ; pas d'autres valeurs
