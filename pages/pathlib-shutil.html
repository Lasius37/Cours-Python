Importer les modules

Le module pathlib permet d'accéder au système de fichiers de l'ordinateur.

Le module shutil permet de copier, déplacer et supprimer des dossiers ou des fichiers. 

import shutil
from pathlib import Path

Créer un chemin

Pour un dossier

my_folder = Path("my_folder")

Pour un fichier

my_file = Path("my_file")

Construire un chemin

DATA = Path("data")
my_file = DATA / "my_file.txt"

Chemin correspondant : data/my_file.txt.

Vérifier l'existence d'un fichier ou d'un dossier

if my_path.exists():
    print("Le chemin existe")

Renvoie True ou False.

Vérifier le type de chemin

if my_path.is_dir():
    print("C'est un dossier")

ou

if my_path.is_file():
    print("C'est un fichier")

Renvoient True ou False.

Récupérer des informations sur un fichier ou un dossier

Exemple :

my_file = Path("C:") / "Folder" / "Sub" / "File.ext"
Information Syntaxe Renvoie
Nom complet 
my_file.name
 File.ext
Nom sans extension 
my_file.stem
 File
Extension 
my_file.suffix
 .ext
Dossier parent 
my_file.parent
 Sub
Chemin absolu 
my_file.resolve()
 C:\Folder\Sub\File.ext

Créer un dossier

Path("folder/sub").mkdir(
    parents=True,  # conseillé ; permet de créer les dossiers intermédiaires si besoin
    exist_ok=True  # conseillé ; évite une erreur si le dossier existe déjà
)

Parcourir un dossier

for path in my_folder.iterdir():
    print(path)  # affiche chaque fichier et sous-dossier

Rechercher des fichiers ou des dossiers

my_files = my_folder.glob("*.txt")  # on récupère tous les fichiers .txt

for file in myfiles:

Si on souhaite inclure les sous-dossier, on utilise la méthode rglob(), qui itère sur les sous-dossiers.

my_files = my_main_folder.rglob("*.txt")

Copier des fichiers ou des dossiers

Pour copier un fichier.

source_file = SOURCE / "filename.ext"  "# SOURCE est un objet Path
target_file = TARGET / "new_filename.ext"  "# TARGET est un objet Path

shutil.copy(source_file, target_file)
shutil.copy2(source_file, target_file)  # copie aussi les métadonnées

Pour copier un dossier.

shutil.copytree(source_folder, target_folder)  # copie également les sous-dossiers
shutil.copytree(source_folder, target_folder, dirs_exist_ok=True)  # autorise la copie même si le dossier cible existe déjà

Déplacer des fichiers ou des dossiers

shutil.move(source_path, target_folder)

Renommer des fichiers ou des dossiers

source_path.rename(target_path)
source_path.replace(target_path)  # renomme en écrasant

Supprimer des fichiers ou des dossiers

Attention, le dossier et son contenu sont supprimés de façon définitive.

my_file.unlink()  # supprime un fichier
my_folder.rmdir()  # supprime un dossier vide
shutil.rmtree(my_folder)  # supprime un dossier et tout son contenu
