    Importer le module

    Le module tkinter permet de créer des interfaces graphiques simples pour des petits projets. Il comporte des widgets assez variés qui permettent à l'utilisateur d'interagir avec le programme. 

    import tkinter as tk

    Créer la fenêtre principale de l'application

    On crée la fenêtre de la façon suivante.

    app = tk.Tk()  # crée une application tkinter

icon = tk.PhotoImage(file="icon.png")  # crée une icône à partir d’un fichier png
app.iconphoto(True, icon)  # affiche l’icône sur la fenêtre de l’appli
app.title("My App")  # donne un titre à l’appli
app.geometry("800x600")  # définit la taille de la fenêtre, en pixels
app.attributes("-fullscreen", True)  # mode plein écran
app.resizable(False, False)  # empêche le redimensionnement
app.configure(bg="#5080d0")  # change la couleur de fond
app.overrideredirect(True)  # supprime la barre de titre et les boutons

app.mainloop()  # lance l’application tkinter ; à placer en fin de fichier

    Utiliser les variables tkinter

    Pour que les widgets soient associés à des données, il faut leur affecter des variables tkinter.

    Types de variables tkinter 
    text = tk.StringVar()
number = tk.IntVar()
state = tk.BooleanVar()
    Associer une variable à un widget 
    my_var = tk.StringVar()

my_entry = tk.Entry(
    app,
    textvariable=my_var
)
    Lire la valeur d'une variable 
    value = my_var.get()
    Modifier la valeur d'une variable 
    my_var.set("New value")

    Dessiner et créer des animations

    On crée d'abord un Canvas.

    my_canvas = tk.Canvas(
    app,
    width=400,   # largeur en pixels
    height=300,  # hauteur en pixels
    bg="white"   # arrière-plan
)

my_canvas.pack()

    On peut dessiner des formes géométriques.

    Ligne 
    my_canvas.create_line(
    50, 50,  # coordonnées du premier point (x, y)
    150, 100  # coordonnées du deuxième point (x, y)
)
    Rectangle 
    my_canvas.create_rectangle(
    50, 50,  # coordonnées du premier coin (x, y)
    150, 100  # coordonnées du deuxième coin (x, y)
)
    Cercle ou ellipse 
    my_canvas.create_oval(
    50, 50,  # coordonnées du premier coin (x, y)
    150, 100  # coordonnées du deuxième coin (x, y)
)
    Polygone 
    my_canvas.create_polygon(
    50, 50,  # coordonnées du premier point (x, y)
    150, 100  # coordonnées du deuxième point (x, y)
    100, 150  # coordonnées du troisième point (x, y)
)

    Il peut être utile de conserver les objets du Canvas pour une réutilisation ultérieure. 

    my_line = my_canvas.create_line(
    50, 50,  150, 100
)

    On peut modifier certains paramètres de ces objets.

        fill="#5080d0",  # couleur de remplissage ou de police
    fill="",  # remplissage vide
    outline="#2b2b2b"  # couleur du contour
    width=5  # épaisseur du contour

    On peut écrire du texte.

    my_canvas.create_text(
    100, 50,
    text="Bonjour",
    fill="#5080d0",
    font=("Arial", 16, "bold")
)

    On peut ajouter une image.

    my_image = tk.PhotoImage(
    file="image.png"
)

my_canvas.create_image(
    200, 150,
    image=my_image
)

    On peut modifier les paraamètres d'un objet du Canvas après sa création.

    my_canvas_object.itemconfig(
    fill="#29d64a"
)

    On peut déplacer un objet.

    my_canvas.move(  # déplace un objet de façon relative
    my_canvas_object,
    10,  # déplacement horizontal
    0  # déplacement vertical
)

my_canvas.coords(  # déplace un objet de façon absolue
    my_canvas_object,
    100, 0  # nouvelles coordonnées
)

    On peut supprimer un objet.

    my_canvas.delete(my_object)

    On peut supprimer tout le Canvas.

    my_canvas.delete("all")

    Accéder aux fichiers

    Importer le sous-module 
    from tkinter import filedialog
    Sélection d'un fichier ou d'un dossier 
    my_file = filedialog.askopenfilename()  # pour un fichier
my_folder = filedialog.askdirectory()  # pour un dossier
    Choisir où enregistrer un fichier 
    my_file = filedialog.asksaveasfilename()

    Organiser l'interface

    Empiler les widgets 
    my_widget.pack(  # tous les paramètres ci-dessous sont facultatifs
    padx=10,  # espace laissé libre horizontalement
    pady=10,  # espace laissé libre verticalement
    fill="both",  # étire le widget : "x", "y" ou "both"
    expand=True  # le widget occupe l’espace libre du conteneur
)
    Organiser les widgets en tableau 
    my_widget.grid(
    row=0,  # numéro de ligne
    column=0  # numéro de colonne
)
    Placer un widget de façon absolue 
    my_widget.place(
    x=100,  # position horizontale
    y=50  # position verticale
)
    Faire des groupes de widgets 
    my_frame = tk.Frame(app)  # crée une boîte vide
my_frame.pack()  # place la boîte

my_button = tk.Button(
    my_frame,  # place le bouton dans la boîte
    text="OK"
)

    Interagir avec l'utilisateur

    Certains widgets peuvent être manipulés.

    Tâche Python
    Associer une fonction à un bouton 
    def my_function():
    print("Clicked !")

my_button = tk.Button(
    app,
    text="Click",
    command=my_function  # Attention : pas de parenthèses !
)
    Lier le contenu d'un Entry 
    text = my_entry.get()
    Vider un Entry 
    my_entry.delete(
    0,  # premier caractère à supprimer
    tk.END  # dernier caractère à supprimer
)
    Écrire dans un Entry 
    my_entry.insert(
    0,  # position où commencer à écrire
    "New text in entry"
)
    Modifier un Label 
    my_label.config(
    text="New label text"
)

    Lier un widget à un événement

    def my_function(event):  # le paramètre event est fourni par tkinter
    ...

my_widget.bind(
    my_event,  # type d’événement
    my_function  # pas de parenthèses
)

    Le paramètre event contient de nombreuses informations.

    Informations du paramètre event
    event.x, event.y position dans le widget
    event.x_root, event.y_root position à l'écran
    event.num Bouton de la souris utilisé (1 : gauche, 3 : droite)
    event.char caractère tapé (a, A, 5, @)
    event.keysym nom de la touche tapée
    event.keycode code numérique de la touche tapée
    event.time horodatage de l'événement en ms
    event.widget obket tkinter concerné
    event.type Type d'événement (ButtonPress, Motion, ...)
    event.state Modificateur clavier (Shift, Ctrl, Alt, souris)

    Types d'événements
    <Button-1>, <Button-2>, <Button-3> Clic de souris (gauche, milieu, droit)
    <Double-Button-1> Double clic gauche
    <ButtonRelease-1> Relâchement clic gauche
    <Motion> Mouvement de souris
    <Enter>, <Leave> Entrée / sortie widget
    <MouseWheel> Molette souris
    <KeyPress> ou <Key> Touche clavier
    <KeyRelease> Touche clavier relâchée
    <Return>, <Escape>, <space>, <Tab>, <BackSpace>, <Delete> Touche spécifique du clavier
    <Left>, <Right>, <Up>, <Down> Flèches
    <Control-c>, <Shift-a>, <Alt-a> Combinaison de touches du clavier
    <FocusIn>, <FocusOut> Focus obtenu / perdu

    Utiliser les boîtes de dialogue

    Importer le sous-module 
    from tkinter import messagebox
    Message d'information 
    messagebox.showinfo(
    "Title",
    "Message"
)
    Message d'avertissement 
    messagebox.showwarning(
    "Warning",
    "Check data"
)
    Message d'erreur 
    messagebox.showerror(
    "Error",
    "File does not exist"
)
    Question oui/non 
    messagebox.askyesno(
    "Confirm",
    "Continue ?"
)
